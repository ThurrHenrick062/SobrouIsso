# 🍳 SobrouIsso — App (React Native + Expo Router)

```bash
npm install
npx expo start
```

Escaneie o QR code com o **Expo Go** (celular e PC no mesmo Wi-Fi) ou aperte `a` para o emulador Android.
Se algo estranho aparecer, limpe o cache: `npx expo start -c`.

O app começa em **modo mock** (dados falsos, sem servidor). Para ligar ao backend, veja `constants/config.ts` e o guia `LEIAME-FRONTEND.md`.
